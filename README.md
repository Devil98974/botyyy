# MinecraftBot

Mineflayer Minecraft Java bot project.

Configured server:
- Host: MoreThanBrotherKMR.aternos.me
- Port: 44659

Run:
1. Install Node.js 18+.
2. `npm install`
3. `npm start`

The bot includes reconnect/error handling and graceful shutdown.

Use automation only where the server and hosting provider permit it. This does not guarantee or provide a bypass of hosting shutdown, resource, or anti-bot restrictions. Never put passwords, tokens, API keys, or other private credentials in a public GitHub repository.
